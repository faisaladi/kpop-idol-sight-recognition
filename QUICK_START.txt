📸 HOW TO ADD ARTISTS:

1. Get clear photos of K-POP artists (front-facing, well-lit)
2. Save them in: backend/photos/
3. Run these commands:

   cd backend
   source venv/bin/activate
   python add_artist.py "Artist Name" "Group Name" "photos/photo.jpg"

   Example:
   python add_artist.py "Jisoo" "BLACKPINK" "photos/jisoo.jpg"

══════════════════════════════════════════════════════════════════════

🎯 HOW TO USE THE APP:

1. Open http://localhost:3000 in your browser (or phone)
2. Allow camera permissions
3. Point camera at K-POP artists (on screen, posters, etc.)
4. Green boxes will appear with artist name and group
5. Click boxes to search Google for more info

🔧 TROUBLESHOOTING:

Camera not working?
  → Check browser permissions
  → Use HTTPS in production
  → Try Chrome browser

No artists detected?
  → Make sure you added artists to the database
  → Check backend: curl http://localhost:8080/health

Backend won't start?
  → Check logs: cat backend.log
  → Verify venv: cd backend && source venv/bin/activate
